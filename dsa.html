WHAT IS DATA STRUCTURE AND ALGORITHM?

A data structure is a specialized format for organizing, processing, retrieving, and storing data in a computer's memory so that it can be accessed efficiently.

WHAT YOU ARE GOING TO LEARNING?

Arrays: A simple, ordered list of items stored right next to each other in memory
Linked Lists: A sequence of items where each item points to the next one
Stacks: Data is added and removed from the top only, following a "Last-In, First-Out"
Queues: Data follows a "First-In, First-Out" rule
